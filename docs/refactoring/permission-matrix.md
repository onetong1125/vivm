# R0：权限、并发及待确认项

日期：2026-09-11。目标规则依据本轮用户明确说明；当前实现依据 Controller/SecurityConfig 静态读取。

| 操作 | 当前观察 | 目标权限 / 条件 | 批次 |
| --- | --- | --- | --- |
| 登录、注册、CSRF | 对三个认证入口 permitAll，其他 API 需 USER/ADMIN | 保持认证边界；失效账户不可访问 | R2 |
| 用户列表/详情/修改/删除 | 路径级 ADMIN | 保持；删除走资源处置流程 | R7 |
| 镜像列表/详情 | 登录角色限制，未统一按归属过滤 | 公共可查看使用；私有不开放他人；管理权限独立 | R3 |
| 克隆镜像 | 当前检查名称、删除状态，缺少统一归属校验 | 自己私有或公共使用；不得依赖他人私有，完整祖先合法 | R5 |
| 删除镜像 | Controller 检查 ADMIN 或 UserImg 归属 | 有管理权再执行依赖/占用策略；公共自由使用不等于可删除 | R5 |
| 创建模板 VM/池 | 登录角色即可进入 | 创建权限需明确授权来源；不得默认所有人有全局池管理权 | R6 |
| 创建克隆 VM | 检查镜像存在/可用，未统一归属 | 私有仅对应用户，公共使用不取得公共镜像写入豁免 | R6 |
| VM 列表/详情/启停/重启/删除 | 登录角色限制，未统一对象授权 | 本人资源或有明确管理权；实时核对运行状态 | R6 |
| 池列表/版本列表 | 登录角色限制 | 按相应池访问权过滤 | R8 |
| 备份/还原池 | 已检查版本归属，但缺少池权限 | 有权限的用户操作对应池；不能收紧成所有操作仅 ADMIN | R7/R8 |
| SSH 管理员旁路 | 应用外执行 | 用户允许；应用承认无法保证旁路并发互斥 | R4/R6 |

## 已确认领域不变量

1. Pool 强绑定一个镜像链，但不是镜像链本身。
2. BASE/DELTA 与 PUBLIC/PRIVATE 独立。公共是自由使用权限；不能依赖私有祖先。
3. 一个镜像可以关联多个 VM；同一可写镜像同时只能一个 VM 运行。
4. 当前写入者对全部祖先持共享读占用；任一祖先已有写者则不能启动后代，已有后代读者则不能启动祖先写者。
5. 兄弟增量可同时运行；停止一个不得清掉另一实例的祖先读占用。
6. 逻辑删除的祖先可以支撑已有后代；物理删除需完整依赖核对。
7. 用户删除保留公共资源、清理私有资源；其他用户/公共资源依赖该用户私有镜像属于非法关系，应在创建时禁止。
8. shutdown 和 destroy 分开；请求关机不等于已停止，未知结果不得释放占用。

## 冲突入口覆盖

| 入口组 | 需要协调的资源 |
| --- | --- |
| createModel | 新池/VM 名称预留、基础镜像、目标写占用 |
| createClone（镜像） | 池结构变更、父及祖先读准入、目标名称 |
| createClone（VM）、start | VM 操作权、目标 WRITE、全部祖先 READ |
| shutdown、destroy、restart、delete VM | 同 VM 操作互斥，远端停止确认与按持有者释放 |
| deleteImage | 当前及后代关系、VM 引用、读写占用、池操作 |
| createBackup | 池结构成员稳定；允许 VM 不停机，不宣称一致快照 |
| restoreBackup | 池独占恢复、全部受影响镜像/VM；运行或未知占用阻止恢复 |
| deleteUser | 账户关闭准入、在途资源创建、所属 VM/私有镜像、涉及的池 |

## 局部未确定项（不是新增需求）

- 公共自由使用是否含在绑定池创建个人增量；建议区分 USE 与池管理，但不能未经确认扩权。
- 创建模板 VM/新池的角色权限、池初始授权来源与赋权管理入口。
- 现有 Vm 无可见性字段；不能由“使用公共镜像”推导 VM 为公共。R7 前确定删除账户的 VM 分类和公共资源管理主体。
- 删除用户的私有内容是否包括历史备份副本；备份恢复不能复活已撤销的用户权限。
- 多用户归属历史数据是否存在，待专用数据副本核查；不能依赖注解推断。

这些项不阻塞 R1 的可测试边界建设；到相应批次时带具体权限/数据方案请用户决定。
